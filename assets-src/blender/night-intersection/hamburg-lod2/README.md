# Hamburg Hansaplatz LoD2 subset

This directory is the source-of-truth geometry subset for the Poly Haven `hansaplatz` reference used by Explore 3D.

- Location: Hansaplatz, Hamburg-St. Georg, Germany
- Reference coordinates: 53.554451, 10.012056
- Provider: Freie und Hansestadt Hamburg, Landesbetrieb Geoinformation und Vermessung (LGV)
- Dataset: 3D-Gebäudemodell LoD2-DE Hamburg 2026
- Source CRS: EPSG:25832
- License: dl-de-by-2.0
- Selection radius: 170 m
- Derived subset: 113 buildings / 339 semantic objects

Do not replace this with Berlin geometry. The previous Berlin/Hamburg pairing was geographically incorrect.
