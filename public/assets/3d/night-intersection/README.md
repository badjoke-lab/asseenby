# Night Intersection runtime assets

Optimized browser/runtime GLB assets for the authored Night Intersection belong here.

The first target is `c0/`, the central 64 m chunk. Runtime files must be generated from or traceable to the Blender/source pipeline defined in `docs/blender-asset-pipeline.md`, then registered in `src/spatial/assetManifest.ts` before production use.

Do not put license-unknown assets here. Do not treat the presence of a GLB as QR1/QR2 acceptance by itself.
